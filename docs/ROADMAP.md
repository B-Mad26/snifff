# Snifff — MVP Roadmap & Growth Strategy

## Phase 1 — MVP (Months 0–6)
**Hypothesis:** pet owners will create profiles, swipe, match, and chat enough to retain at 30% D7.

Ship list:
- Auth (phone OTP + Apple/Google)
- Single pet profile creation with AI bio
- Sniff stack — Friends mode only, PostGIS shortlist + compatibility re-rank
- Mutual match + Bumble-style 24h chat window
- Real-time text/photo chat (Socket.io)
- Basic photo feed (no Tails yet)
- Push notifications (match + message)
- Reports + block + basic moderation
- Web landing page with waitlist

**KPIs to hit before Phase 2:** 25K downloads · 30% D7 retention · 5+ swipes per active user per day · 1.2 viral coefficient on referrals.

---

## Phase 2 — Expansion (Months 7–12)
**Hypothesis:** with content + multi-mode, we become the default pet app.

Ship list:
- Multi-pet support per user
- Tails (vertical video feed) with algorithmic ranking
- Stories (24h)
- Map view (nearby pets)
- Adoption Mode + partner with 50 shelters
- Verified Vet badge program
- ID Verification (Persona/Veriff)
- AI Breed Identifier in onboarding
- AI Caption suggestions
- Snifff+ subscription ($9.99/mo)
- Voice + video calls in chat (LiveKit)

**KPIs:** 1M MAU · 5% paid conversion · $2M ARR · 40% D30 retention.

---

## Phase 3 — Scale (Months 13–24)
**Hypothesis:** multi-modal + marketplace creates a flywheel competitors can't replicate.

Ship list:
- Breeding Mode + Breeder Pro tier ($39.99/mo) + lineage tools + AKC API integration
- Lost Pet Mode with geo-broadcast
- Playdate scheduling (calendar + map)
- Marketplace (treats, toys, services) with 15% take rate
- Live Bark (live streaming + virtual gifting)
- Insurance partnerships
- International expansion: UK · Canada · Australia · India
- Web parity with mobile core features

**KPIs:** 10M MAU · 7% paid · $50M ARR.

---

## Phase 4 — Empire (Months 25–48)
- Snifff Vet (telehealth)
- Snifff Travel (pet-friendly booking)
- Snifff Insurance (own brand, white-labeled)
- M&A: regional pet apps, breed clubs
- Path to IPO / strategic acquisition at $250M+ ARR

# Growth Strategy

## A. Pre-launch (90 days before public launch)

- **Closed alpha** in 3 cities: Austin, SF, Brooklyn — 200 users each, recruited via vet partnerships
- **Influencer onboarding** — 50 pet creators signed (10K–1M followers each) with paid + equity hybrid deals
- **Waitlist landing page** with referral mechanic — invite N friends to skip the queue
- **Content seeding** — Snifff creates 200 TikToks featuring real alpha users' pets

## B. Launch (90-day window)

| Window | Focus | Target |
|---|---|---|
| Day 0–30 | 3-city launch; paid TikTok | 100K downloads |
| Day 30–60 | US-wide soft launch; ProductHunt; PR push | 300K · first viral Tail |
| Day 60–90 | Snifff+ paid launch; partnership deals | 750K · $250K MRR |

## C. Channels (Year 1)

| Channel | Tactic | Why it works |
|---|---|---|
| **TikTok** | 500 pet creator partnerships; #SnifffMatch challenges | Pets are TikTok's top organic engagement category |
| **Instagram** | Famous-pet ambassadors; Reels-first; shareable Snifff Cards | Direct match-→ IG story export drives backlinks |
| **Vet clinics** | Co-branded sign-up at puppy intake | High-intent moment, low CAC |
| **PetSmart / Chewy** | In-store displays + packaging insert | Captive audience |
| **Rescue orgs** | Adoption-success Snifff Stories | PR + emotional virality |
| **Referral** | "Bring a pup, get a Boost" | Target viral coefficient 0.5 |
| **City unlock** | 1K pets per city → physical launch party + local press | Concentrated network effect |
| **ASO** | Title: "Snifff: Pet Dating & Friends"; sub: "Match. Play. Adopt. Sniff." | Long-tail breed/city keywords |
| **SEO** | Public pet pages SSR-indexed; adoption directory goldmine | Long-tail compounding |

## D. Retention Strategy

- **Daily Tails** algorithm
- **Weekly Snifff Picks** curated matches push
- **Pet Birthdays** auto-celebrations with shareable card
- **Milestone Tracker** (first walk, first vet visit, etc.)
- **Snifff Memories** yearly recap (Spotify Wrapped for pets)
- **Comeback Engine** — 7-day inactive users get AI-personalized "Luna misses you" notification
- **Streaks** — daily login chain unlocks Super Sniffs

## E. PR Hooks (always-on)

- "Tinder for Dogs" press angle (universal hook)
- Most Matched Dog of the Year — annual award
- Lost-pet hero stories (community recoveries)
- Adoption success stories
- City-level pet personality reports
